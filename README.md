# AI Agent Documentation Knowledge Base

This repository is a read-only knowledge base for AI agents working on applications and software projects.

Its purpose is to give AI agents a trusted place to find official documentation links for the technologies used in a project.

Agents should use the documentation referenced here to understand how a framework, SDK, database, or service is intended to work before proposing changes to an application.

## Current Documentation

This knowledge base currently includes documentation for:

- AI SDK
- TanStack
- Neon

Additional technologies may be added as the project grows.

## Purpose

AI agents may access this repository to:

- Find official documentation links.
- Research the correct implementation of a feature.
- Understand framework and SDK behavior.
- Verify APIs, message formats, persistence patterns, routing behavior, database behavior, and other technical requirements.
- Avoid guessing how a technology works.
- Avoid inventing unsupported implementation patterns.

The links and documentation references contained here are intended to be used as technical source material when working on external projects.

## No Application Changes

This repository is NOT the application being worked on.

Access to this repository does NOT grant permission to modify the actual application or project.

An AI agent may use information found here to understand a technology and then explain or propose changes for another project.

It must not make changes to an external application merely because documentation in this repository describes a particular implementation.

Application changes require the user's separate and explicit authorization.
